# 온콜 운영 규정

> 교육용 더미 데이터입니다.

## 1. 근무 형태

온콜은 주 단위로 순환하며 매주 월요일 오전 10시에 인수인계합니다.
인수인계는 대면 또는 화상으로 진행하며, 문서만 전달하는 방식은 허용하지 않습니다.

야간 호출(22시~08시)에 대응한 경우 다음 영업일 오전 근무가 면제됩니다.
대응 시간이 2시간을 넘으면 해당 영업일 전일 휴무로 대체할 수 있습니다.

온콜 담당자는 호출 후 15분 내 응답 가능한 상태를 유지해야 합니다.
장거리 이동이나 통신이 불가능한 일정이 있으면 사전에 대체자를 지정합니다.

## 2. 에스컬레이션

1차 담당자가 15분 내 응답하지 않으면 2차 담당자에게 자동 전달됩니다.
2차도 15분 내 응답이 없으면 팀장에게 전달됩니다.

P1 장애는 15분 규칙을 적용하지 않고 1차와 2차를 동시에 호출합니다.
팀장에게도 즉시 알림이 전달되며, 별도 승인 없이 대응 채널이 개설됩니다.

외부 벤더 지원이 필요한 경우 팀장 승인 후 벤더 긴급 지원 창구로 연락합니다.
벤더 응답 시간은 계약 SLA에 따르며, 초과 시 계약 담당자에게 에스컬레이션합니다.

## 3. 인수인계 항목

미해결 이슈 목록, 진행 중인 배포, 알려진 알람 소음을 문서로 남깁니다.
각 항목에는 현재 상태와 다음 조치, 관련 티켓 번호를 함께 적습니다.

지난 주에 발생한 P1·P2 장애는 원인과 조치 결과를 요약해 전달합니다.
아직 근본 원인이 밝혀지지 않은 건은 그 사실을 명시합니다.
